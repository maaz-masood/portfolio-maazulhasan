Projects

Enhancing Predictive Modelling in Neurological Care Using Federated Learning

Developed a privacy-preserving Alzheimer’s prediction model using Federated Learning, enabling multiple hospitals to collaboratively train a machine learning model without sharing sensitive patient data. Leveraged Python and AI frameworks to preprocess multi-center medical datasets, handle missing values, and engineer meaningful features. Evaluated model performance using metrics such as accuracy, precision, recall, and AUC, ensuring reliable predictions. Maintained compliance with HIPAA and GDPR regulations, preserving patient privacy while improving predictive accuracy and demonstrating the potential of federated learning in healthcare.

Predictive Sales Analytics

Created a predictive model using Python and machine learning techniques to forecast sales trends for a retail business. Preprocessed historical sales data, engineered relevant features, and implemented model evaluation using metrics like RMSE, MAE, and R² to ensure accuracy. Developed visualizations in Power BI and Tableau to present sales predictions and actionable insights. The solution enabled the business to anticipate demand, optimize inventory, and improve sales strategy, highlighting the impact of data-driven decision-making.
